## About Me

I'm a Data Science & AI graduate from **Al-Hussein Bin Talal University**, based in Aqaba, Jordan.

I build practical projects using **AI agents, n8n, and computer vision**. Most of my recent work focuses on connecting AI models, APIs, and different tools to create useful applications and automate real tasks. I enjoy learning by building and improving projects through hands-on work.

## Selected Projects

- **[Dobi Kitchen — Multi-Agent Assistant](https://github.com/FY0499/Dobi-Kitchen-Multi-Agent-Assistant):** I built a Telegram assistant that routes customer requests to the right workflow for orders, cancellations, and delivery questions.
- **[Multi-Agent Management Orchestrator](https://github.com/FY0499/Multi-Agent-Management-Orchestrator):** An n8n workflow that coordinates specialized agents to handle management-related requests.
- **[Smart Vision System](https://github.com/FY0499/blind):** A computer vision project that detects objects and text, estimates relative distance, and provides Arabic audio guidance.
- **[Sign-to-Text](https://github.com/FY0499/Sign-to-Text):** Analyzes sign-language video and turns the signs into text and spoken output.
- **[Text-to-Sign-Language](https://github.com/FY0499/Text-to-Sign-Language):** Converts written text or speech into a sign-language video.
- **[AI Travel Planner](https://github.com/FY0499/AI-Travel-Planner):** Collects trip preferences and prepares a personalized itinerary using information from external APIs.
- **[SHEIN Order Assistant](https://github.com/FY0499/Shein-Order-Assistant):** Helps customers submit and confirm SHEIN orders through Telegram.
- **[AI Phishing Email Triage](https://github.com/FY0499/AI-Phishing-Email-Triage):** Analyzes incoming emails, identifies possible phishing signs, and sends alerts.
- **[Invoice Data Extraction](https://github.com/FY0499/Invoice-Data-Extraction):** Extracts structured information from PDF invoices.
- **[AI Content Repurposer](https://github.com/FY0499/AI-Content-Repurposer):** Turns one piece of content into posts for different social media platforms.
